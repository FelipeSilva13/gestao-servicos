# 🛠️ Sistema de Gestão de Serviços

Este projeto é um sistema web desenvolvido com **Spring Boot**, **Thymeleaf** e **MySQL**, projetado para auxiliar no gerenciamento de serviços técnicos, como instalações elétricas, energia solar, CFTV e manutenção predial.

O sistema faz parte do Trabalho Acadêmico do curso de **Análise e Desenvolvimento de Sistemas (Uniasselvi)** e será aplicado em uma instituição concedente, com visitas presenciais e validação real.

---

## 🚀 Tecnologias Utilizadas

- **Java 21**
- **Spring Boot 3**
  - Spring Web
  - Spring Data JPA
- **Thymeleaf**
- **MySQL 8**
- **Hibernate**
- **Maven**
- **HikariCP**
